# studentRecordSystemAsgm
A C++ program for Student Record System for assignment. The primitive version aim for assignment, later version to make enhancement 
Version 1: array data structure along with secondary school student record
Version 2: linked list data structure along with university student record, which have mre feature
Version 3: a branch of version 2 but BST and queue data structure. The objective is to learn the data structure of BST
Version 4: Combined by Version 1 and Version 2, with more function.
